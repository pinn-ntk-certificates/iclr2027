\section*{Compatible-target rank and conditioning results}
Completed 1080/1080 compatible controls: 600 manufactured-target runs and 480 compatible contrast-target runs. Every reported target is functionally compatible. This reporting overlay reuses the original completed trajectories.

For duplicate rows $\ell_1=\ell_2$ with equal targets, the normalized residual lies in the range of the rank-one kernel. All 120 retained duplicate-row runs use manufactured targets; 118 reached $L_T<10^{-12}$. Singularity therefore does not preclude convergence for these compatible targets.

The loss is $L(\theta)=\sum_{i=1}^2(\ell_i[u_\theta]-y_i)^2$. Full-batch gradient descent uses $\theta_{t+1}=\theta_t-2\eta J_t^\top e_t$, with $\eta=0.2/\lambda_{\max}(K_0)$. Frozen dynamics satisfy $e_{t+1}=(I-2\eta K_0)e_t$. A frozen eigenmode with eigenvalue $\lambda>0$ has squared-loss factor $(1-2\eta\lambda)^2$; smaller gaps permit slower convergence.
